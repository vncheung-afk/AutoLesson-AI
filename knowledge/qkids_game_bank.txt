QKIDS GAME BANK FRAMEWORK (Select 2 varied games per lesson):

1. VOCABULARY GAMES

- What's Missing?
  Tools: 4 stickers/pictures on screen. Teacher covers one item.
  Teacher says: "Open your eyes! What's missing?"
  Student output: "The [shoe] is missing."

- Invisible Man
  Tools: Blank underscores on screen for a vocab word's letters. A stick figure appears piece by piece with each wrong letter guess.
  Teacher says: "Guess a letter! Don't let the invisible man appear completely!"
  Student output: "Is there a [B]?" ... then, once revealed: "The word is [book]!"

2. GRAMMAR & SENTENCE GAMES
- Sentence Builder
  Tools: Word/picture blocks pre-placed on screen (Dog | is | eating | meat).
  Student output: "The dog is eating meat."

- Choice Combo
  Tools: 3 columns on screen (Who? / Action / Thing).
  Student output: "The dog is eating cake."

- Two Truths and a Lie (Fact Checker)
  Tools: 3 statements about the page picture displayed on screen (2 real, 1 fake).
  Teacher says: "Which statement is a lie?"
  Student output: "Statement 2 is a lie! The dog is sleeping, not running."

3. PHONICS / RHYMING GAMES
- Rhyme Detective
  Tools: Target word + 3 word choices.
  Student output: "Bear rhymes with chair."

- Sound Hunt
  Teacher says: "Find things on screen with the /b/ sound."
  Student output: "Book starts with /b/."

4. PICTURE BOOK THINKING GAMES
- Story Relay
  Tools: None needed — uses the book's characters or a page event as the starting point.
  Teacher says: 3 words to start the story ("Once upon a...").
  Student output: Adds the next 3 words, alternating turns with the teacher to build a complete mini-story together — practicing sentence flow and tracking what's already been said.
